====================================================================
        ccd_helper - 外观检查辅助系统 使用与功能指导文件
====================================================================

【1. 系统概述】
ccd_helper 是一款基于 Windows Forms 和 DirectShow 的工业视觉辅助软件。
它用于协助操作员在 CCD 摄像头下进行产品外观检查，支持分步骤展示标准样图、
工具样图、看板信息，并记录检查结果（良品/不良品）。

核心特性：
- 多项目/多版本配置加载
- 实时摄像头预览（支持帧率调整）
- 分步操作指引（步骤图/工具图/看板图）
- 鼠标/键盘快捷操作
- 结果记录与日志导出
- 硬件授权与有效期保护

--------------------------------------------------------------------

【2. 目录与文件结构】
2.1 程序运行目录要求
   └── Data/                      （数据根目录，需放在程序启动目录或当前工作目录）
       ├── 项目名称/              （例如：ProjectA）
       │   └── 版本号/            （例如：V1.0）
       │       ├── config.json    （必需：检测配置文件）
       │       ├── step_01.jpg    （示例：步骤图片）
       │       ├── tool_01.jpg    （示例：工具图片）
       │       └── board_01.jpg   （示例：看板图片）
       └── sequence.dat           （授权有效期文件，由程序生成/验证）

2.2 日志目录
   程序启动后会在 `Logs/` 下自动生成 CSV 日志文件，文件名格式为 `yyyy-MM-dd.csv`。

2.3 用户配置保存路径（由 SelectionForm 使用）
   D:\ccd_helper\config.json      （保存用户上次选择的项目、版本、摄像头、帧率等）

【3. 授权与启动机制 (Program.cs)】
3.1 单实例保护
   - 使用互斥体 "Global\\796796797" 确保程序同时只能运行一个进程。

3.2 硬件授权验证（固定密钥）
   - 检查文件是否存在：`C:\Program Files\ccd_helper\license`
   - 文件内容必须为纯文本：`HF796`（UTF-8 编码，无 BOM）。
   - 若文件不存在或内容不匹配，程序直接退出。

3.3 有效期验证（动态授权）
   - 验证文件：`Data/sequence.dat`（Base64 编码）。
   - 解密逻辑：Base64 解码 → XOR 解密（密钥 0x3C）→ UTF-8 字符串（日期格式，如 2026-12-31）。
   - 若解析出的日期早于当前日期，或文件不存在，则弹出 `LicenseInputForm` 输入授权码。
   - 授权码输入后，程序重新计算日期并写入 `sequence.dat`，继续启动。

3.4 启动流程
   - 授权通过 → 启动 `SelectionForm` → 用户选择配置 → 启动 `Form1` 主界面。

--------------------------------------------------------------------

【4. 配置选择界面 (SelectionForm.cs)】
4.1 功能
   - 扫描 `Data/` 目录下的所有“项目/版本”，仅加载包含 `config.json` 的有效版本。
   - 使用 DirectShowLib 扫描系统所有视频输入设备（摄像头），供用户选择。
   - 设置目标帧率（5~60 FPS）和 VMR9 刷新间隔（0~30 分钟）。

4.2 数据持久化
   - 用户点击“确定”后，所有选择项被保存到 `D:\ccd_helper\config.json` 中。
   - 下次启动时自动回填上次的选择（项目、版本、摄像头、帧率、刷新间隔）。

--------------------------------------------------------------------

【5. 检测配置格式 (InspectionConfig.cs & config.json)】
`config.json` 必须符合以下 JSON 结构，并放置于项目版本目录下。

{
  "Tools": [
    {
      "ToolsImage": [ "tool_01.jpg", "tool_02.jpg" ]   // 工具区显示图片（相对路径）
    }
  ],
  "Steps": [
    {
      "StepId": 1,
      "StepImages": [ "step_01.jpg", "step_02.jpg" ], // 步骤区显示图片
      "BoardImages": [ "board_01.jpg", "board_02.jpg" ] // 看板区图片（每 2 张为一组翻页）
    }
  ],
  "ErrorReason": [ "划痕", "气泡", "异物", "尺寸超差" ] // 不良原因下拉列表
}

注意：
- 图片文件名均为相对路径，程序会在当前版本目录下加载。
- Steps 数组至少包含一个 Step，否则程序会进入空状态。
- BoardImages 每 2 张为一组，支持分组切换。

【6. 主界面布局与交互 (Form1.cs)】
6.1 窗口结构
   - 主窗体 `Form1` 背景为黑色，使用 `TransparencyKey = Color.Magenta` 实现透明镂空。
   - 子窗体 `FormVideo`（无边框、无任务栏）完全覆盖 `Form1` 的内部客户区，用于渲染视频。
   - `FormVideo` 设置 `SetWindowPos` 常驻于 `Form1` 下方（Z-Order），确保鼠标事件正确穿透。

6.2 网格布局（4列 × 3行）
   - 列宽：1/4, 1/2 (中间两列合并), 1/4
   - 行高：1/3, 1/3, 1/3

   【步骤区】    【工具区】    【看板区】
   (0,0)         (1-2,0)       (3,0)
   【图片放大区(点击图片后弹出)】 (1,1) 覆盖区域
   【控制面板】                   (3,2)

6.3 控制面板（右下角）
   - 良品按钮（绿色）：点击弹出结果录入窗口（判定为良品）。
   - 不良品按钮（红色）：点击弹出结果录入窗口（判定为不良品，并列出原因）。
   - 计划按钮（灰色）：点击重新加载配置选择界面（关闭当前视频，重新选择并加载）。
   - 水印：显示当前项目名与版本名。

6.4 图片放大功能
   - 鼠标左键点击步骤区/工具区/看板区内的任何图片，该图片会以最大比例显示在中间行（第 1 行）。
   - 点击放大区域任意位置，放大视图关闭，恢复主界面。

【7. 操作手势与快捷键】
7.1 鼠标操作（主窗体 Form1）
   - 左键点击图片 → 放大该图片。
   - 左键点击“良品/不良/计划”按钮 → 对应功能。
   - 点击放大图 → 关闭放大。

7.2 鼠标操作（视频子窗体 FormVideo）
   - 左键点击视频区域 → 后退（上一组看板 / 上一步骤）。
   - 右键点击视频区域 → 前进（下一组看板 / 下一步骤）。

7.3 键盘快捷键
   - Enter 键 → 重置到第一步（DisplayStep(0)）。
   - Esc 键 → 退出整个应用程序。
   - 左方向键 (←) → 同“视频左键点击”（后退）。
   - 右方向键 (→) → 同“视频右键点击”（前进）。

7.4 步进逻辑
   - 若当前看板组未到最后一组 → 切换到下一组看板。
   - 若看板已到最后一组 → 切换到下一个步骤（步骤索引+1）。
   - 若是最后一个步骤的最后一组看板 → 弹出提示“所有步骤已完成！”。

【8. 视频渲染与内存管理】
8.1 渲染引擎
   - 使用 DirectShow 的 FilterGraph 构建：Source Filter → VMR9（Windowless 模式）。
   - 通过 `IVMRWindowlessControl9` 将视频绘制到 `FormVideo` 的 HWND 上。

8.2 帧率设置
   - 枚举摄像头的所有支持格式，匹配目标帧率（误差 ±1 FPS），通过 `IAMStreamConfig.SetFormat` 应用。

8.3 内存刷新（防老化）
   - 用户可配置“刷新间隔（分钟）”，默认 5 分钟。
   - 定时器触发时调用 `IVMRWindowlessControl9.SetVideoPosition` 重新设置视频区域，用于解决长时间运行下 VMR9 显示冻结或黑屏问题。
   - 若间隔设为 0，则禁用定时器。

--------------------------------------------------------------------

【9. 结果记录 (ResultForm.cs & WriteLog)】
9.1 结果录入窗口
   - SN 号输入框（必需）。
   - 不良原因复选框列表（来自 config.json 的 ErrorReason 字段）。
   - 若判定为“良品”，不良原因复选框自动禁用。
   - 窗口大小可自由调整，且会通过注册表（`HKCU\Software\ccd_helper\ResultForm`）记忆上次的宽高。

9.2 日志写入
   - 日志路径：`Logs/yyyy-MM-dd.csv`
   - CSV 格式（4列）：类型, SN, 原因列表, 时间
   - 原因列表使用 `;` 分隔。
   - 字段自动转义（包含逗号、引号、换行符时用双引号包裹）。

示例：
良品,SN12345,,2026-07-31 14:30
不良品,SN67890,"划痕;气泡",2026-07-31 14:35

【10. 常见问题排查】
10.1 启动时提示“授权失败！请确保 C:\ccd_helper\license 文件存在”
   - 请检查 `C:\Program Files\ccd_helper\license` 文件是否存在，内容是否为 `HF796`（无空格/换行）。

10.2 启动时弹出授权码输入框
   - 说明 `Data/sequence.dat` 过期或不存在。
   - 您需要向管理员获取新的授权码（一个 Base64 字符串，解码后为未来日期）。

10.3 提示“未找到 Data 文件夹！”
   - 确保 `Data` 文件夹位于程序启动目录（`Application.StartupPath`）或当前工作目录下。

10.4 提示“未找到配置文件：...”
   - 检查对应项目版本目录下是否包含 `config.json`，且 JSON 格式正确（参考第 5 节）。

10.5 视频窗口黑屏或无画面
   - 检查摄像头是否被其他程序占用。
   - 检查“目标帧率”是否被摄像头硬件支持（程序自动匹配，若无可匹配则使用默认格式）。
   - 尝试调整“刷新间隔”为一个非零值（如 5 分钟），以触发 VMR9 表面刷新。

10.6 图片无法显示
   - 确认 `config.json` 中引用的图片文件名与实际文件完全一致（包括扩展名大小写）。
   - 图片必须位于与 `config.json` 相同的版本目录下。
